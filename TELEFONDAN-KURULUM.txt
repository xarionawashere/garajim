GARAJIM — ANDROID / GOOGLE PLAY DERLEME KILAVUZU

BU KLASORDE HAZIR APK/AAB YOKTUR. APK/AAB GitHub Actions tarafinda olusturulur.

1) GitHub'da bos bir repo olustur (or. garajim). ZIP'i acip proje kokundeki TUM dosyalari/klasorleri repoya yukle. Ozellikle .github/workflows/build-apk.yml, scripts/, native-android/, build-web.js, tw-input.css, tailwind.config.js, package.json, capacitor.config.json, index.html, icon.png ve icon-foreground.png dosyalarini unutma. node_modules/, android/ ve www/ yukleme; bunlar derlemede olusur.
2) Actions sekmesinde “Android APK ve Google Play AAB Olustur” is akisini calistir. Ilk derleme bagimliliklari indirir; hata olursa logdaki ilk hata satirini kontrol et.
3) Sadece debug APK test icin uretilir. Google Play'e yuklemek icin imzali AAB gerekir; release derlemesi icin asagidaki secrets degerlerini ekle.

KALICI IMZA (BIR KEZ OLUŞTUR)
Java yüklü bilgisayarda terminal: 
  keytool -genkeypair -v -storetype PKCS12 -keystore garajim.p12 -alias garajim -keyalg RSA -keysize 2048 -validity 10000
Sonra Base64 olustur:
  base64 -w0 garajim.p12 > keystore-base64.txt
Windows PowerShell alternatif:
  [Convert]::ToBase64String([IO.File]::ReadAllBytes('garajim.p12')) | Set-Content -NoNewline keystore-base64.txt
GitHub repo > Settings > Secrets and variables > Actions > New repository secret:
  KEYSTORE_BASE64   = keystore-base64.txt icerigi
  KEYSTORE_PASSWORD = anahtar deposu parolasi
  KEY_ALIAS         = garajim
  KEY_PASSWORD      = anahtar parolasi
Anahtari ve parolalari guvenli, ayrica bir yerde yedekle; kaybolmasi guncelleme yayimlamayi engelleyebilir. Asla GitHub'a .p12/.jks veya parola dosyasi olarak yukleme.
