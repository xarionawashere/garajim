GARAJIM TELEFON + WEAR OS BAGLANTI DUZELTMESI

BU ZIP APK DEGIL, GITHUB ACTIONS ILE APK URETMEK ICIN KAYNAK PROJEDIR.

Yapilan degisiklikler:
- Wear OS modulu applicationId degeri telefon uygulamasi ile ayni olacak sekilde com.garajim.app yapildi.
- Saat uygulamasinin Java namespace'i com.garajim.wear olarak birakildi; bu, sinif yoludur ve applicationId'den ayri olabilir.
- Telefon uygulamasi acildiginda ilk Wear OS durum bilgisini gondermeye calisiyor.
- Saat uygulamasi acildiginda daha once senkronize edilmis en son surus durumunu okumaya calisiyor.
- GitHub Actions telefon ve Wear OS APK'larini ayri artifact olarak yukler; Wear derleme hatasi gizlenmez.

GITHUB'A YUKLEME:
1. Bu ZIP'i bilgisayara cikart.
2. Icinden cikan proje dosyalarini GitHub deposunun ana dizinine yukle; dosyalarin .github/workflows, native-android, native-wear ve scripts klasorleri dahil korunmali.
3. Degisiklikleri main veya master dalina gonder.
4. GitHub > Actions > APK Olustur ekraninda calismanin bitmesini bekle.
5. Ayni calistirmanin icinden hem Garajim-Mobil-APK hem Garajim-WearOS-APK artifact'larini indir. Eski bir calistirmadan APK'lari karistirma.

KURULUM NOTLARI:
- Wear OS APK'sinin applicationId'si eski surumdeki com.garajim.wear yerine com.garajim.app olur. Bu nedenle yeni saat APK'sini kurmadan once saatteki eski paket kaldirilmalidir:
  adb -s SAAT_SERI_NUMARASI uninstall com.garajim.wear
- Sonra ayni yeni Actions calistirmasindan cikan Wear OS APK'sini saate yukle.
- Telefon ve saat icin ayni Actions calistirmasindan cikan APK'lari kullan; Wearable Data Layer uygulama kimligi ve imza uyumuna ihtiyac duyar.
- Telefon uygulamasini kaldirma. Once Garajim'in kendi yedekleme ozelligiyle yedek olustur ve yedek dosyasini uygulama disinda PC'ye/Drive'a kopyala.
- Telefon APK'si yuklenirken uygulama guncellenemiyor veya imza uyusmazligi hatasi verirse eski telefon uygulamasini kaldirma; hata mesajini kontrol et.

IMZALAMA UYARISI:
- Workflow, KEYSTORE_BASE64, KEYSTORE_PASSWORD, KEY_ALIAS ve KEY_PASSWORD GitHub Actions secrets degerleri varsa sabit release imzasi kullanir.
- Bu secrets yoksa debug APK'lar uretilir. Farkli GitHub Actions calistirmalari arasinda debug imzasi ayni kalmayabilir; dolayisiyla sonraki telefon guncellemeleri reddedilebilir. Uzun vadeli guncellemeler icin ayni ozel release keystore'un GitHub secrets ile yapilandirilmasi gerekir.

DOGRULAMA:
Bu kaynak paketi burada bir Android build sunucusunda APK olarak derlenip gercek Galaxy Watch uzerinde test edilmemistir. GitHub Actions sonucu dogrulanmalidir.


SAATTEN ARAÇ SEÇİMİ VE SÜRÜŞ KAYDI KONTROLLERİ
- Telefon JS katmanı araç listesini /garajim/vehicles yoluyla saate gönderir.
- Saatteki Araç seç düğmesi seçili aracı telefonun aktif Garajım WebView oturumuna iletir.
- Bitir onayı saatte açılır. Sürüş bitince özet saat ekranında Kaydet/Sil/Sonra seçenekleriyle yönetilebilir.
- Telefon ekranı öne getirilmeden komut, aynı süreçte çalışan mevcut WebView oturumuna gönderilir. Telefon uygulaması süreci tamamen kapalıysa JS tabanlı GPS/sürüş mantığı o anda çalışmadığından yeni sürüş başlatma/durdurma komutları işlenemez; uygulamayı sürüş boyunca arka planda açık tutmak gerekir. Araç seçimi bu durumda kuyruğa alınır.
