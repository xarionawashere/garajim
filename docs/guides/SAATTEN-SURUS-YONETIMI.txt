GARAJIM 1.3.8 — SAATTEN SÜRÜŞ KONTROLLERİ

Bu kaynak güncellemesi, telefon ve Galaxy Watch7 arasındaki sürüş akışını saate taşır:

- Araç listesi (plaka / marka / model) telefondan ayrı Wear OS Data Item olarak senkronize edilir.
- Saatteki “Araç seç” düğmesi araç listesini açar ve seçim telefonun JS sürüş oturumuna iletilir.
- Saatten başlat / duraklat / devam komutları verilebilir.
- “Bitir” düğmesi telefon ekranındaki JavaScript confirm penceresini kullanmaz; kısa sürüş kontrolü saatte gösterilir.
- Sürüş bitince mesafe/süre/ortalama/maksimum bilgileri saatten gözden geçirilir; “Kaydet”, “Sil” ve “Sonra” seçenekleri saatten seçilebilir.
- Saatten gelen komutlar, telefon Garajım Activity/WebView hâlâ arka planda varsa o oturuma doğrudan iletilir; telefon Activity’si öne getirilmez.

GÜNCELLEME ADIMLARI
1. ZIP'i kendi GitHub deposunun yerel kopyasına çıkar ve dosyaların üzerine yaz.
2. Değişiklikleri main/master dalına commit edip push et.
3. GitHub Actions'ta aynı çalıştırmadan hem Garajim-Mobil-APK hem Garajim-WearOS-APK artifact'larını indir.
4. Telefon APK'sını ve Wear OS APK'sını ilgili cihazlara install -r ile kur. Telefon uygulamasını kaldırma.
5. Güncellemeden sonra Garajım'ı telefonda bir kez aç ve araç listesinin Watch7'ye senkronize olması için birkaç saniye bekle. Ardından telefon ekranından çıkıp uygulamayı arka planda bırakabilirsin.

ÖNEMLİ SINIR — 1.3.5
`GarajimRideService`, önceden hazırlanmış foreground servis üzerinden native GPS örnekleme, sürüş durumu ve saat komutlarını destekler. Native sürüş modu devralındıktan sonra telefon ekranı/WebView görünür olmak zorunda değildir. Yine de bu durum her telefon/OEM pil politikası için mutlak bağımsızlık anlamına gelmez: uygulama zorla durdurulursa, konum izni kaldırılırsa, konum/GPS kapatılırsa veya Android servisi başlatmayı engellerse sürüş kaydı/komutlar aksayabilir. İlk kurulumdan sonra Garajım'ı telefonda açıp izinleri ver ve bildirimin/servis hazırlığının geldiğini kontrol et.

1.3.5'te müzik komutları WebView yokken native Android medya denetimine yönlendirilir. Park yeri native depoda saklanabilir; saat mesafe ve yönü yalnızca son GPS konumu iki dakikadan yeni olduğunda gösterir. Bu iki davranış fiziksel Galaxy Watch7 üzerinde ayrıca test edilmelidir.

DOĞRULAMA
- index.html içindeki inline JavaScript blokları node --check ile doğrulandı.
- XML kaynakları XML parser ile doğrulandı.
- Bu çalışma ortamında Android SDK/Gradle ve npm bağımlılıkları bulunmadığından tam APK derlemesi burada yapılmadı; son derlemeyi GitHub Actions yapmalıdır.

GÜVENLİK / KAYIT DAYANIKLILIĞI
- Bitirilen sürüş özeti, saatten Kaydet/Sil kararı gelene kadar garaj_ride_watch_pending anahtarıyla yerel depoda tutulur.
- Uygulama yeniden açılırsa bekleyen özet geri yüklenip saate yeniden bildirilir.
- Kayıt listesine yazma başarısız olursa bekleyen özet hemen silinmez; saatten tekrar denemeye uygun biçimde tutulur.
- Araç listesi gönderim önbelleği, yalnızca Wear OS Data Layer gönderimi başarılı olduktan sonra güncellenir; geçici hata olursa yeniden gönderim denenebilir.


1.3.8 NOTU — KOMUT ACK KURTARMA
- Saat ekranı uykuya girerken bekleyen komut kimliği yerel olarak korunur. Yeniden açılışta kalıcı Data Item ACK'si okunmaya çalışılır ve kurtarma penceresi yeniden başlatılır.
- Bu, bağlantı ve uyku senaryolarında kaybolan onay ihtimalini azaltır; fiziksel Galaxy Watch7 üzerinde test edilmeden kesin garanti kabul edilmemelidir.
